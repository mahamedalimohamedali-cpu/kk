# CLI Assistant

CLI Assistant is a professional desktop productivity tool designed to streamline content creation, language translation, and social media automation using Google’s Gemini AI. The application provides a centralized interface for transforming raw data into polished, professional-grade communications.

## Key Features

*   **AI-Driven Translation and Editing:** Provides automated English-to-Arabic translation and high-level English grammar correction using the Gemini-3-Flash-Preview model.
*   **Dynamic Post Generation:** Transforms project descriptions into engaging, emoji-rich Facebook posts formatted specifically for developer groups and professional audiences.
*   **Integrated Social Media Automation:** Features direct integration with the Facebook Graph API to publish AI-generated content to specific groups without leaving the application.

## Technical Stack

*   **Language:** C#
*   **Framework:** .NET / Windows Forms
*   **AI Integration:** GenerativeAI (Google Gemini API)
*   **API Communication:** HttpClient for RESTful interactions with the Facebook Graph API
